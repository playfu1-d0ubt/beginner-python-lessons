# Lesson 1: Variables

## The idea

A variable is a labelled box. The label is the name. The thing inside is the value.

| Code | Box label | Inside the box |
|---|---|---|
| `age = 16` | age | 16 |
| `name = "Sam"` | name | "Sam" |

## Try it

```python
age = 16
print(age)
age = 17
print(age)
```

| Line | What happens | Box `age` holds |
|---|---|---|
| `age = 16` | Make box, put 16 in | 16 |
| `print(age)` | Show what is inside | 16 |
| `age = 17` | Throw out old value, put 17 in | 17 |
| `print(age)` | Show what is inside | 17 |
